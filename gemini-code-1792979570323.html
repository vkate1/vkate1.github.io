CS601: Machine Learning

Master core principles of machine learning—from foundational probability, regression, and optimization to advanced deep learning, convolutional networks, sequence models, and reinforcement learning.

Course Objectives

Foundational Theory

Understand foundations of machine learning: data, statistics, linear algebra, convex optimization, and supervised & unsupervised paradigms.

Deep Neural Networks

Design, train, and tune feedforward neural networks, convolutional neural networks (CNNs), and sequence models using TensorFlow & Keras.

Advanced Learning Paradigms

Apply reinforcement learning (MDP, Q-learning, SARSA), support vector machines (SVM), and Bayesian inference to complex environments.

Real-World Applications

Deploy ML models for practical domain problems in Computer Vision, Natural Language Processing (NLP), and Speech Processing.

Unit-Wise Assignments

Learners submit one comprehensive PDF solution per unit containing 5 descriptive questions.

Assignment 1 Unit I: Introduction and Data Foundations
  1. Differentiate supervised and unsupervised learning with two real-world examples each.
  2. Explain min-max normalization and standardization. Normalize the data values 10, 20, 30, 40, 50 to the range 0 to 1.
  3. Fit a straight line to the points (1,2), (2,3), (3,5) using least squares linear regression.
  4. Define a convex function mathematically and explain why convexity matters in numerical optimization.
  5. Explain hypothesis testing (null hypothesis, alternative hypothesis, p-value) and list four image data augmentation techniques.
Assignment 2 Unit II: Neural Network Fundamentals
  1. Compare sigmoid, tanh, and ReLU activation functions, including their mathematical formulas and derivatives.
  2. Write the gradient descent update rule and explain the effect of learning rate size on model convergence.
  3. Explain backpropagation for a neural network with one hidden layer using a step-by-step numerical example.
  4. Explain the unstable (vanishing and exploding) gradient problem and how weight initialization (Xavier/He) mitigates it.
  5. Compare dropout, L1 regularization, L2 regularization, and batch normalization, explaining the role of momentum and hyperparameter tuning.
Assignment 3 Unit III: Convolutional Neural Networks
  1. For a 32×32 input, a 5×5 filter, padding 2, and stride 1, find the output feature map size, and calculate the trainable parameters for 16 filters on 3 input channels.
  2. Draw the architecture of a CNN for handwritten digit recognition and explain the role of convolution, max pooling, flattening, and dense layers.
  3. Explain 1×1 convolution and the computational benefits of the Inception module architecture.
  4. Differentiate transfer learning and one-shot learning with real-world examples.
  5. Implement a CNN for the MNIST dataset in TensorFlow/Keras and report test accuracy and training loss curves.
Assignment 4 Unit IV: Sequence Models and Reinforcement Learning
  1. Explain how a Recurrent Neural Network (RNN) is unrolled over time and why standard RNNs struggle with long-range temporal dependencies.
  2. Draw the gating mechanism inside an LSTM and GRU cell, comparing their state update mechanisms.
  3. Explain beam search decoding with a beam width of 2 on a small sequence example, and define the BLEU score metric.
  4. Define state, action, reward, and policy in a Markov Decision Process (MDP). Write the Bellman expectation equations and compare value iteration vs policy iteration.
  5. Compare Q-learning (off-policy), SARSA (on-policy), and Actor-Critic architecture.
Assignment 5 Unit V: SVM, Bayesian Learning and Applications
  1. Explain the maximum margin classifier, support vectors, soft margin slack variables, and the kernel trick in Support Vector Machines.
  2. State Bayes' theorem and solve a numerical example of Naive Bayes classification for text/data.
  3. Describe three major applications of machine learning in modern Computer Vision.
  4. Explain the end-to-end processing pipeline for Speech Processing or Natural Language Processing (NLP).
  5. Write a concise case study on the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) and its transformative impact on deep learning.
